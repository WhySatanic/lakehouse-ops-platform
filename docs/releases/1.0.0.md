# Version 1.0.0 acceptance manifest

Version `1.0.0` is the first stable release of the Lakehouse Ops Platform public control
plane and local reference stack. Promotion requires one successful `main` workflow run
whose source revision is also the release tag target.

## Required capability evidence

| Capability | Executable gate |
|---|---|
| Stable CLI and JSON contract | `quality` verifies control-plane contract `1.0.0` |
| MinIO to Spark to Iceberg/Hive Metastore to Trino | `lakehouse-integration` |
| Centralized Ranger authorization | `ranger-integration` |
| Prometheus, Grafana, SLOs, and alert delivery | `lakehouse-integration` |
| Metastore, metadata database, and worker recovery | `lakehouse-integration` |
| Optional direct-Iceberg serving path | `serving-integration` |
| Cross-profile invariant attestation | `release-readiness` |
| Clean checkout and retained publication bundle | `release-candidate` |
| Trino upgrade, rollback, and target restoration | RC bundle upgrade report |

The release-candidate archive must report `status: ready`, reference the tag commit, and
contain the attestation, both contracts, every attested evidence report, the pinned Trino
upgrade plan, its four-phase report, and a digest manifest. The archive and its JSON
report are release assets, not temporary CI-only evidence.

## Supported contract

- `lakeops` command names and long options listed in
  `config/control-plane/contract.json` are stable.
- Public JSON reports remain on their declared schema major.
- Additive commands, options, fields, and enum values are compatible.
- Removals, renames, type changes, or semantic incompatibilities require a new product
  major with migration and rollback guidance.

## Known limitations

- The stack is a deterministic local reference environment, not a capacity-tested,
  highly available, TLS-enabled, or multi-region managed service.
- The Trino drill covers a full-cluster 482 to 483 transition, rollback, and restoration;
  it does not prove a mixed-version rolling upgrade.
- Registry image IDs are recorded during the drill, but Compose image references are not
  pinned by registry digest.
- ClickHouse is an optional serving experiment and not part of the core query contract.

## Upgrade from 0.48.0

No CLI command, long option, configuration key, or JSON field is removed. Version
`1.0.0` changes the stability commitment and SemVer policy, not the runtime topology.
Operators should retain the release-candidate archive, verify its SHA-256, and use the
documented Trino rollback plan for engine upgrades.
