# Version 1.21.0 release notes

Version `1.21.0` extends graceful Trino worker drain to the opt-in authenticated Ranger
profile. The drill observes an active task on a private worker, requests shutdown through
the operator authorization path, proves that the same query finishes without
interruption, verifies Iceberg state through the surviving worker, and restores full
capacity.

## Capability matrix

| Capability | Status | Evidence |
|---|---|---|
| Verified HTTPS transport | Implemented | Client trusts the generated Trino certificate |
| Password-authenticated query | Implemented | `platform_admin` submits and completes the observed query |
| Ranger-authorized drain | Implemented | `lakehouse-operator` transitions the assigned worker to `SHUTTING_DOWN` |
| Zero query interruption | Implemented | Exact observed query reaches `FINISHED` before worker exit |
| Degraded read continuity | Implemented | Iceberg fingerprint succeeds with one worker |
| Secure topology restoration | Implemented | Drained worker is recreated and three active nodes return |
| Audit correlation | Implemented | Both report identities have allowed Ranger audit decisions |
| Default HTTP drain | Preserved | Existing Compose check and report semantics remain compatible |

The required Ranger integration job must validate and retain
`trino-authenticated-worker-shutdown.json`, validate the ordinary authenticated access
matrix, and correlate both shutdown identities with the retained Ranger Solr audit.

## Known limitations

- Zero interruption is proven for one observed read-only synthetic query, not writes or
  every possible workload shape.
- The five-second grace period is a bounded development and CI setting, not a production
  recommendation.
- Worker management traffic stays on the private Compose HTTP network; external client
  traffic crosses the verified TLS/password coordinator boundary.
- Worker-to-coordinator traffic uses a shared secret, not mutual TLS.
- The certificate and password file are development-only fixtures.
- Coordinator failover and simultaneous multi-worker drain are not covered.

## Upgrade from 1.20.0

No warehouse, metastore, CLI, or public JSON migration is required. The new runner is an
additive CI and operator drill. Existing default-profile shutdown commands remain valid.

Rollback omits the authenticated shutdown step or returns to the default shutdown check.
The drill recreates the drained worker and does not mutate Iceberg tables, Hive Metastore
state, Ranger policy, or default Trino configuration.
