# Version 1.15.0 release notes

Version `1.15.0` adds an opt-in, atomic refresh workflow for public output schema digests.
Maintainers can update all reviewed schema bindings and immediately run the stable
control-plane compatibility gate with one command.

## Capability matrix

| Capability | Status | Evidence |
|---|---|---|
| Atomic schema digest refresh | Supported | The contract is replaced through a temporary file in the same directory |
| Immediate compatibility verification | Enforced | The CLI verifies the refreshed contract before reporting success |
| Read-only default | Preserved | Omitting the new flag performs verification without changing the contract |
| Reviewable schema identity | Preserved | All 11 public output schemas retain normalized SHA-256 bindings |
| Stable control-plane verification | Preserved | 17 commands, 37 critical option semantics, and 11 outputs are checked |

## Verification

```bash
uv sync --frozen --dev
uv lock --check
uv run ruff check .
uv run lakeops verify-control-plane-contract --contract config/control-plane/contract.json
uv run lakeops verify-image-lock
uv run pytest
docker compose --profile catalog --profile compute --profile query --profile security --profile observability --profile serving config --quiet
```

## Known limitations

- Refreshing hashes records the current schema bytes but does not establish semantic
  backward compatibility. The schema diff, producer tests, and contract result still need
  review.
- The refresh rewrites the contract using the canonical indented JSON layout, so the first
  run can include formatting changes alongside digest updates.
- The stack remains a local reference environment, not a capacity-tested or multi-region
  managed service.

## Upgrade from 1.14.10

No data, infrastructure, dependency, or report migration is required. Existing invocations
remain read-only. Maintainers may add `--refresh-schema-digests` only when intentionally
updating reviewed public schemas. Rolling back removes the convenience workflow but retains
the schema digest enforcement introduced in `1.14.10`.
