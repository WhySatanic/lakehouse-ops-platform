# Version 1.26.0 release notes

Version `1.26.0` extends observability acceptance from infrastructure reachability to a
delivered data-quality SLO breach. CI now proves that the intentionally stale ingestion
fixture produces the expected Alertmanager notification at the webhook boundary.

## Capability matrix

| Capability | Status | Evidence |
|---|---|---|
| Selectable alert identity | Implemented | The checker requires the configured alert name |
| Exact label matching | Implemented | Optional instance and component labels are matched exactly |
| Freshness breach delivery | Implemented | CI receives `LakehouseIngestionFreshnessSLOBreach` |
| Core-target compatibility | Implemented | Existing firing and resolved target checks are unchanged |
| Production paging | Not included | The local webhook remains an executable acceptance boundary |

## Verification

```bash
uv sync --frozen --dev
uv lock --check
uv run ruff check .
uv run pytest
docker compose --profile observability config --quiet
```

The lakehouse integration job must first prove the stale freshness objective, retain the
breach beyond the alert's five-minute pending period, and then match the delivered alert
name and ingestion component. It separately rehearses the existing core-target firing and
resolved lifecycle.

## Known limitations

- The drill verifies local Alertmanager-to-webhook delivery, not an external paging vendor.
- It exercises the ingestion-freshness breach; query-success and maintenance-backlog alert
  delivery remain covered by rule validation rather than injected end-to-end failures.
- The stale fixture is deterministic CI data and is not a production incident source.

## Upgrade from 1.25.0

No data, catalog, policy, CLI, or public JSON migration is required. Custom invocations of
`alert-delivery-check` keep the core-target defaults. Set `EXPECTED_ALERT_NAME`, clear
`EXPECTED_ALERT_TARGET`, and optionally set `EXPECTED_ALERT_COMPONENT` to verify another
alert family. Rollback removes the additional CI drill and restores the previous fixed
core-target checker configuration.
