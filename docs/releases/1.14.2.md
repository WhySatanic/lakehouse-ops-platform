# Version 1.14.2 release notes

Version `1.14.2` makes schema definitions part of the executable control-plane gate.
Every declared public output schema is loaded and checked against the Draft 2020-12
metaschema before the contract can be accepted.

## Capability matrix

| Capability | Status | Evidence |
|---|---|---|
| Public-output schema loading | Supported | The compatibility gate loads all 11 declared schema files |
| Draft 2020-12 metaschema validation | Supported | Invalid schema keywords and values fail the gate before producer execution |
| Runtime report validation | Preserved | Current producers validate emitted reports against the same loaded definitions |
| Stable control-plane verification | Preserved | 17 commands, 36 critical option semantics, and 11 outputs are checked |
| Shared schema loader | Supported | Definition loading and validation use one error boundary for the gate and producers |

## Verification

```bash
uv sync --frozen --dev
uv lock --check
uv run ruff check .
uv run lakeops verify-control-plane-contract --contract config/control-plane/contract.json
uv run lakeops verify-image-lock
uv run pytest
docker compose --profile catalog --profile compute --profile query --profile security --profile observability --profile serving config --quiet
```

## Known limitations

- Metaschema validation proves that each schema definition is structurally valid; runtime
  producer tests remain responsible for proving report conformance and business invariants.
- The gate does not fetch remote references. Current schemas are self-contained and use
  local definitions only.
- The stack remains a local reference environment, not a capacity-tested or multi-region
  managed service.

## Upgrade from 1.14.1

No data, infrastructure, CLI, or report migration is required. Existing repository
schemas pass the Draft 2020-12 definition check. Custom contract extensions with malformed
schemas now fail closed and must correct their definitions. Rolling back removes this
definition-validation gate but leaves runtime producer validation unchanged.
