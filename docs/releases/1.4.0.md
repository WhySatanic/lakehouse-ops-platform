# Version 1.4.0 release notes

Version `1.4.0` adds the first standalone Draft 2020-12 JSON Schema to the stable
control plane and validates the contract-verifier report before reporting success.

## Capability matrix

| Capability | Status | Evidence |
|---|---|---|
| Verifier report JSON Schema | Supported | Versioned schema freezes fields, types, constants, digest format, and additional-property policy |
| Runtime report validation | Supported | `verify-control-plane-contract` validates its emitted report with `jsonschema` |
| Invalid schema or report rejection | Supported | Focused tests exercise schema drift and validation failure |
| Stable CLI semantics | Preserved | 17 commands and 26 critical option semantics remain checked |
| Other public report schemas | Planned | Ten existing producer reports still rely on executable producer tests |
| Core lakehouse, Ranger, observability, and recovery | Preserved | Required GitHub Actions integration jobs |

## Verification

```bash
uv sync --frozen --dev
uv run ruff check .
uv run lakeops verify-control-plane-contract --contract config/control-plane/contract.json
uv run pytest
docker compose --profile catalog --profile compute --profile query config --quiet
```

## Known limitations

- Only the control-plane verifier report has a standalone schema in this release.
- Schema migration for the remaining ten reports will ship incrementally with fixtures.
- The stack remains a local reference environment rather than a capacity-tested,
  highly available, TLS-enabled, or multi-region managed service.

## Upgrade from 1.3.1

Install the updated runtime dependencies and retain the same command invocation. No CLI,
data, or infrastructure migration is required. Rolling back removes runtime schema
validation but leaves the report structure unchanged.
